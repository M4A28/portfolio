# Project screenshots

Drop app screenshots here and they appear on the projects section automatically — no `data.json` editing.

- One folder per project, named **exactly** like the project's `repo` (case matters, even on Windows):

  `KqrCode`, `nawif_app`, `count_down`, `qr_lens`, `Towmmen`, `Color_Extractor`, `Sahihain`, `Certificate_Maker`

- Name files so they sort in display order: `1.png`, `2.png`, ... `10.png`
- Supported formats: `png`, `jpg`, `jpeg`, `webp`
- An empty folder is fine — the project falls back to its current single image.

Clicking a project's thumbnail opens a lightbox gallery; the first screenshot becomes its thumbnail on the site.
