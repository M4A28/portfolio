## Feature: Project screenshot galleries (lightbox)

**How it works for you afterwards:** create a folder per project under `src/assets/shots/` named exactly like the repo (e.g. `KqrCode`, `nawif_app`, `Towmmen`...) and drop screenshot files in (`1.png`, `2.png`, ...). They appear automatically — no data.json editing. Until a folder has images, the project keeps its current single image / placeholder.

### Changes

1. **New `src/screenshots.ts`** — auto-discovery via Vite's `import.meta.glob('./assets/shots/**/*.{png,jpg,jpeg,webp}')`, grouped by folder name and sorted by filename (numeric-aware so `2.png` comes before `10.png`). Exports `screenshotsByRepo: Record<repoName, url[]>`.

2. **`src/components/Projects.tsx`** — reuse the existing `Certificates.tsx` lightbox pattern:
   - Per project: `screenshots = screenshotsByRepo[repo]`, falling back to the old single `img`. Thumbnail becomes a button when images exist (cursor-zoom-in + a small screenshot-count badge).
   - Click opens a fullscreen lightbox: dark blurred overlay, centered image (`max-h-[80vh]`, portrait-friendly), project title caption with "n / total" counter, prev/next chevron buttons, X close.
   - Keyboard: Escape closes, arrow keys navigate; backdrop click closes; body scroll locked (same as Certificates).
   - RTL-aware: chevrons flip with `rtl:-scale-x-100` like the rest of the site; single-screenshot projects hide the arrows/counter.

3. **`src/data.json` + `src/content.ts`** — add two `labels` strings (`prev`/`next`) to the ar and en trees for the lightbox buttons' aria-labels.

4. **Scaffold** `src/assets/shots/` with the 8 repo-named folders (`.gitkeep` so git tracks them) + a short README explaining the drop-in convention and the exact-name/casing requirement.

5. **Fix 2 latent bugs found while exploring** (verify actual filenames first):
   - data.json references `certificate_maker.png` / `color_extractor.png` but the real files are `Certificate_Maker.png` / `Color_Extractor.png` — works on Windows, will 404 on a Linux host. Fix the references.
   - English `Color_Extractor` entry has `"img": ""` while Arabic has the image — set it to match.
